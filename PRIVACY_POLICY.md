# HandyHub GDPR / CCPA Compliance

## Data Collection Disclosure

### What We Collect
- Email address (authentication)
- Full name (profile)
- Phone number (optional, for service providers)
- Service preferences and booking history
- Payment information (via Stripe/PayPal, not stored locally)
- Location data (optional, for service matching)

### How We Use Data
- Provide service marketplace functionality
- Match customers with service providers
- Process bookings and payments
- Send service-related notifications
- Improve service recommendations
- Verify provider credentials

### Data Rights (GDPR)
Users have the following rights:
- **Access**: Request a copy of all personal data
- **Rectification**: Update incorrect or incomplete data
- **Erasure**: Request data deletion ("right to be forgotten")
- **Portability**: Receive data in a structured format
- **Restriction**: Limit how data is processed
- **Objection**: Opt out of specific processing

### Data Deletion
Users can request data deletion:
1. Go to Profile > Settings > Privacy
2. Click "Request Data Deletion"
3. Confirm deletion via email
4. Data is permanently deleted within 30 days

## Cookie Disclosure
This application uses session cookies for authentication. No tracking cookies are used without explicit consent.
